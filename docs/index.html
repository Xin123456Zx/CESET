Overview

Consider cosmologists studying how matter clusters in the universe. They have 380 Nyx simulations in hand, and every new one costs hours on a supercomputer. Answering even simple questions — is this run unusual? what would a slightly different matter density produce? which parameters give me this filament structure? — currently means jumping between ensemble analysis scripts, surrogate model code, volumetric processing, and disconnected visualization tools.

CESET brings those steps into a single interactive visual workflow. It couples ensemble exploration with an uncertainty-aware neural surrogate, so a new parameter configuration can be evaluated in seconds instead of hours — complete with disentangled aleatoric and epistemic uncertainty and prediction intervals that carry a coverage guarantee. It then closes the loop with a gradient-based inverse search that recommends plausible parameters for a target spatial structure, ranked by the scientist's own uncertainty preferences, and a context-aware AI assistant that explains what is on screen.

The tool is built for 3D ensemble simulation datasets in general; this demonstration uses the Nyx cosmology ensemble as its running example. CESET is open source — see the repository for the code, the pretrained surrogate, and the setup guide.

  • Ensemble Data Understanding

    Large-scale ensembles make it difficult to jointly characterize distributions, identify outliers, and assess parameter sensitivity.

  • Uncertainty-Aware Surrogate Access

    Surrogates predict outputs and quantify uncertainty quickly, but using them still requires model code, volumetric processing, and separate visualization tools.

  • Preference-Guided Parameter Exploration

    Gradient-based optimization can infer plausible parameters from target outputs and uncertainty preferences, but inverse exploration remains hard without interactive support.

  • Context-Aware AI Assistance

    Domain scientists may be unfamiliar with machine-learning surrogates, and uncertainty concepts are often ambiguous; they need explanations tied to the interface in front of them.

01

Ensemble Data Understanding

Purpose. Provide a unified interactive visual workflow for comprehensive exploration of the existing ensemble.

Every member of the ensemble becomes one point in the landscape scatterplot: the horizontal axis is the mean of its log-density field, the vertical axis the standard deviation, and color separates the training, calibration, and testing splits used to build and evaluate the surrogate. Statistical and structural outliers are ring-marked, so unusual runs surface immediately.

Selections propagate across every view. Narrow the ensemble with parameter filters, jump to a member by id or parameter value, or brush an axis of the parallel-coordinates view — the landscape follows. Clicking a member shows its simulation parameters, field statistics, and an interactive 3D density field on the right, while the sensitivity panel reports how the field statistics move with each simulation parameter.

  • Ensemble distribution overview
  • Statistical analysis
  • Outlier detection
  • Parameter sensitivity analysis
  • Interactive 3D member inspection
02

Uncertainty-Aware Surrogate Prediction

Purpose. Provide an interactive visual interface for accessible and interpretable exploration of surrogate predictions and their uncertainty.

The user sets the three Nyx parameters and submits. Within a few seconds, without touching the simulator, the surrogate returns a predicted 3D field together with aleatoric uncertainty (variability modeled in the data itself) and epistemic uncertainty (what the learned model does not know) — rendered side by side so it is clear where a prediction is uncertain and which kind of uncertainty dominates.

A region of interest along the X, Y, and Z axes is shared by every view, and all volume renderings move under one synchronized camera, so the same spatial structures can be compared directly. Choosing a confidence level and clicking Render shows the raw prediction interval and its bounds — higher confidence, wider interval — and clicking Calibrate replaces them with conformalized bounds, which under the standard exchangeability assumption carry a finite-sample marginal coverage guarantee.

The surrogate builds on our previous work on conformalized evidential learning, ConfEviSurrogate, which predicts simulation outputs with competitive reconstruction accuracy, disentangles aleatoric from epistemic uncertainty, and produces calibrated intervals at user-specified confidence levels.

  • Interactive parameter queries
  • Linked prediction, aleatoric & epistemic uncertainty
  • User-controlled confidence
  • Raw vs. calibrated intervals
  • Shared ROI and synchronized cameras
03

Preference-Guided Parameter Exploration

Purpose. Recommend plausible simulation parameters that match scientists' target outputs and uncertainty preferences.

This module answers the inverse question: given a desired spatial structure, which parameter settings are likely to produce it? Clicking Optimize on a prediction in Module 2 sends it here as the context field. The user boxes a region of interest, picks a reference field as the spatial target, states a preference for high or low aleatoric and epistemic uncertainty, and clicks Recommend Parameters.

The system searches the parameter space by differentiating the surrogate with respect to the simulation parameters, and returns several candidate configurations with their matching errors and uncertainty summaries. The spatial matching objective decides how well a candidate reproduces the target feature; the uncertainty preferences break ties among candidates of similar matching quality. Any candidate can be previewed in place, or sent back to Module 2 for forward visual verification.

These recommendations do not replace expensive simulations — they narrow the parameter space so scientists can prioritize promising configurations for subsequent simulator validation. A neural-network-based sensitivity analysis at the bottom of the view shows which parameters most strongly influence the selected region.

04

Context-Aware AI Assistance

Purpose. Provide context-aware explanations and workflow guidance grounded in the current interface state and a curated knowledge base.

Uncertainty-aware surrogate analysis involves concepts and workflows that may be unfamiliar to domain scientists, so an assistant is available throughout all three modules. Using retrieval-augmented generation, it combines the user's question and the current session state with knowledge of the CESET workflow and passages retrieved from a curated knowledge base.

Ask, for example, "How does Recommend Parameters work in the Para-space view?" — the assistant answers using the live workflow context and cites its supporting references, so the explanation stays traceable and verifiable rather than free-floating.

Get CESET running

The repository ships the pretrained Nyx evidential surrogate and the precomputed ensemble statistics, so the tool runs out of the box on a machine with an NVIDIA GPU. Full instructions, optional data, and the guide for adapting CESET to another 3D ensemble dataset are in the repository README.

# clone
git clone https://github.com/Xin123456Zx/CESET.git && cd CESET

# backend (CUDA build of PyTorch, then the rest)
python -m venv .venv && source .venv/bin/activate
pip install torch==2.2.2 --index-url https://download.pytorch.org/whl/cu121
pip install -r backend/requirements.txt

# frontend
cd frontend && npm install && cd ..

# run both, then open http://localhost:5173
./start_demo.sh

CESET is dataset-agnostic. Adapting it to another 3D ensemble means training an evidential INR with the shipped architecture, registering the dataset's parameter ranges in the backend and its parameter panel in the frontend, precomputing the ensemble statistics with the included scripts, and optionally precomputing conformal calibration fields.
